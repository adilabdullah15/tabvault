# TabVault — Chrome Web Store listing copy (policy-safe, 2026-09-26)

## Title
TabVault — Auto-Save Tab Manager

## Short description
Never lose a tab again. TabVault auto-saves your windows, organizes tabs into workspaces, and restores everything in one click.

## Detailed description
TabVault automatically saves your browser windows, so you never lose important tabs again — even after a crash or restart.

KEY FEATURES
• Automatic snapshots — every window is saved continuously in the background
• Named workspaces — group tabs by project: Work, Thesis, Trip planning…
• Global search — find any tab across all workspaces instantly
• One-click restore — reopen a whole window or workspace exactly as it was
• Backup status pill — see at a glance when your last backup happened
• Import / export — your data stays portable

PRIVACY FIRST
Your tabs never leave your device. Everything is stored locally in your browser — no accounts, no analytics, no tracking. The optional in-app feedback sends only what you type to the developer's private sheet.
